# Security

Read the [threat model](docs/security.md) and [requirement gaps](docs/requirements.md)
before production use. Report privately through
[GitHub security advisories](https://github.com/RESOAuth/cloudfront-soca-plugin/security/advisories/new).
Never include a ZIP, keys, live callback URL, token or cookie in a public issue.
The initial supported line is 0.1.x. Fix confirmed high/critical issues before
production release; this MVP has no published response SLA yet.
